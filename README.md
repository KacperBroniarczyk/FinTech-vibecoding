# FinTech VibeCoding

A 4-week intensive project building a secure, cloud-native AI banking agent. Built with a strict focus on software engineering best practices, data security, and cloud deployment.

## Tech Stack
- Core:Python 3.11, FastAPI, Pydantic, asyncio, Docker
- AI & Data: GCP Vertex AI, Gemini, LangGraph, Qdrant (RAG)
- Domain: FinTech (Anti-Fraud, Data Anonymization, Financial Precision)
